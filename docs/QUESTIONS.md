## 方針として決めたこと（確認不要、異議があれば教えてください）

- GPS の品質フィルタ：`status=="A"` かつ `sats ≥ 5` かつ `hdop ≤ 5` の行だけを使う。
- 停止判定：`speed_kmh < 5`。
- 帯域特徴量（計画書 9.4）は fs ≈ 398 Hz なので実装する（ナイキスト 199 Hz）。**ただし FFT は合成加速度ではなく、窓内平均を引いた 3 軸それぞれに掛けてパワーを足す**：合成（絶対値）にすると整流で周波数が 2 倍に写り、アイドリングの 24 Hz の山が 48 Hz に見えてしまうため。RMS・p2p・crest・jerk は計画書どおり重力除去後の合成加速度で計算する。
- GPS の追加チェック：RMC の速度と、連続 fix 間の距離から求めた速度の差が 25 km/h を超える行（`gps.max_speed_mismatch_kmh`）は無効にする。ride_004 14:15:53〜14:16:07 の「RMC は 3 km/h なのに位置は 40 km/h 相当で動く」区間がこれで落ちる。
- 位置情報の実値（緯度・経度）はノートブック出力・ドキュメント・コミットに含めない。軌跡は最初の fix からの相対距離（m）で描く。地図タイルは folium（OpenStreetMap）で、ブラウザがタイルを取る際にタイル座標がタイルサーバーに送られる点は静的 HTML でも避けられない（マスク済みの範囲だけを描く）。
